# 06_Story_PG1

**PG1 Demo 的故事内容包**（可推翻的实验层，不是最终产品形态）。

这里放「写进 Demo 的事件与演出」，不是 Voice / Intent / GameSystem 引擎。

## 子目录分工

| 目录 | 含义 | 谁该改 |
|------|------|--------|
| `Spine/` | **主线锚点链**：关 AI 也必须能走通的必经 beat（Commission → CoPresence → Deviation → Ending） | 核心作者；改结构需对照 `Design/` 宪章锚点 |
| `Optional/` | **非必定触发**的共创空间：支线、偶发相遇、可跳过事件 | 共同创作者优先扩展这里 |
| `Playback/` | **演出壳**：`StoryDirector`、黑屏旁白、Hint、Trigger——负责「怎么播」，不写 PG1 剧情内容本身 | 改通用播片能力时动这里 |

## 命名取舍（Story vs Spine）

- **Story_PG1（本目录）** = 整包故事**内容面**：主线 + 可选 + 播片工具放一起，方便别人找「我要加一段戏」该去哪。
- **Spine** = 只表示主线里由**结构锚点**串起来的那条脊骨，不是全部故事。
- **Playback**（不用再叫 Story）= 避免与父目录 `Story_PG1` 撞名；强调它是播放/演出基础设施。

## 约定

- 新事件若**不是**三日必经锚点 → 进 `Optional/`，不要塞进 `Spine/`。
- Spine 内具体事件与台词默认可推翻；不可推翻的是宪章里的锚点结构本身。
