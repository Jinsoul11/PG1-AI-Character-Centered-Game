## 开发者亲测（游戏内真实流程）

脚本库（F10 / F11）验收告一段落；下一步**不再用测试脚本灌 Archive**，在正式 Demo 里对话、切日结算、走到 Ending，按真实链路验收。

### 怎么跑

1. Play 进入三日 Demo，按正常 Presence / 找书 / 共处流程玩。
2. 自由对话写入 Archive；切日或 Settle 走 Filter → Curator → Unit → Analyzer → FM。
3. 到 Ending 看 Bond（及 Recap 若启用）；可用 F9 面板核对各层，但**不要**按 F10/F11 覆盖语料。
4. 结果记下方表格：初始列写**游玩摘要**（天数、场景、聊了什么），不贴全文。

### 建议关注

- 寒暄是否被 Filter 挡掉；有料句是否进 Curator
- 主语是否「玩家 / Remi」清晰；Bond 是否编语料外事件
- 无印象时是否宁缺 skip；有冲突/和好跨日时 Ending 站在哪一段
- Bond 温度是否只会「暖」；与专项/盲测是否同气质
